# 添加工作会话布局约束

这个页面用于一次完成“连接机器、选择 AI 类型、添加工作目录”。界面必须像原生 iOS/iPadOS 设置页一样清楚、可操作，不允许做成 PC 表单换皮。

## 页面结构

页面只允许三层主结构：

1. 顶部标题区：`添加工作会话`、说明文案、右上角关闭按钮。
2. 内容滚动区：连接信息、工作目录。
3. 底部操作区：固定在底部，只放一个主要按钮 `添加 N 个会话`。

不要在“服务器 / 连接信息”外再包一层二级目录，也不要把扫描按钮重复放到底部。

## 连接信息

连接信息是一张表单卡片，字段顺序固定：

1. 会话名称：可为空，placeholder 是 `不填则自动命名`。
2. AI 类型：只能在创建会话前选择，创建后不可修改；要换 AI 类型必须重新创建一个新会话。
3. 服务器类型：例如 `Linux`、`Windows PowerShell`。
4. 服务器地址：IP 或域名。
5. 端口：独立一行。
6. 用户名：独立一行。
7. 登录密码：独立一行，可见并支持复制。

端口和用户名必须是两行，禁止合并成 `端口 / 用户名` 或 `22 · root`。

`AI 类型` 只能在连接信息里出现一次。禁止在工作目录区域、目录列表上方或底部按钮附近再放第二个 Codex/Claude 选择器。

## 工作目录

工作目录标题和说明必须放在卡片外面，位于卡片上方：

```jsx
<section className="session-import-block">
  <div className="session-import-label">
    <strong>工作目录</strong>
    <span>可以扫描已有 AI 会话，也可以手动输入路径</span>
  </div>
  <div className="session-import">
    ...
  </div>
</section>
```

`.session-import-label` 不能有背景、边框或大卡片视觉，只是卡片的外部标题说明。

`.session-import` 卡片内部只放操作内容：

1. 自动扫描：标题 `自动扫描`，按钮 `开始扫描` 或 `重新扫描`，说明文案在该行下面。
2. 手动添加：标题 `手动添加`，右侧是普通路径输入框，最右是 `添加` 文字按钮，说明文案在该行下面。
3. 搜索和目录列表：只有扫描结果或手动添加结果存在时展示。

手动添加说明文案必须在手动添加这一块底部单独占一行，不能挤在标题左侧，也不能和输入框抢同一行。

手动添加输入框保持轻量边框和浅控制背景，按钮使用和自动扫描一致的次级按钮样式。禁止改成透明设置行，禁止使用只有图标的小按钮。

## 字体规范

添加工作会话页必须使用固定字号，不允许使用 `vw` 按视口缩放字体，也不允许负字距。

| 场景 | 字号 | 字重 | 行高 | 备注 |
|---|---:|---:|---:|---|
| 页面标题 | 24px / iPhone 22px | 760 | 1.12 | 不得超过 24px |
| 页面副标题 | 12px | 400 | 1.32 | 灰色辅助信息 |
| 区块标题 | 17px | 720 | 1.2 | 例如“工作目录” |
| 区块说明 | 12px | 400 | 1.38 | 放在卡片外 |
| 表单字段名 | 13px | 560 | 1.25 | 例如“用户名” |
| 表单输入值 | 14px | 400 | 1.25 | IP、端口、用户名等 |
| 方法标题 | 14px | 700 | 1.25 | 自动扫描、手动添加 |
| 方法说明 | 12px | 400 | 1.38 | 独立一行 |
| 目录名称 | 14px | 700 | 1.25 | 目录列表主标题 |
| 目录路径/元信息 | 12px | 400 | 1.3 | 路径可以用等宽字体 |
| 普通按钮 | 13px | 700 | 1 | 高度 34-36px |

## 滚动和安全区

必须满足这些约束：

- 页面不能横向滚动。
- iPhone 主页面是全屏原生布局，不允许出现浏览器式外层横竖滚动条。
- 内容过长时，只允许内容区纵向滚动，底部按钮固定在安全区上方。
- 键盘弹起时，输入框和底部按钮必须仍可见。
- iPad 使用居中面板或双栏布局，但同样不能出现横向滚动。
- 工作目录列表可在卡片内部滚动，不能把底部按钮挤出屏幕。

## 视觉规则

- 卡片圆角 16-20px，按钮圆角 12-14px。
- 主按钮使用系统蓝色；次按钮使用浅灰控制背景。
- 按钮高度保持一致，不能一个大一个小。
- 选中态使用轻量背景，不要强蓝色边框。
- 不允许卡片套卡片；自动扫描和手动添加是同一张工作目录卡片里的两个分隔行。
- 文案要短，避免解释性长段落占据操作区域。

## 状态规则

- 未填写服务器地址、端口、用户名、密码时，不允许扫描。
- 扫描和手动添加都只是把目录加入候选列表，不会立即创建会话。
- 只有勾选了至少一个目录后，底部 `添加 N 个会话` 才可点击。
- 手动输入路径后点击 `添加`，该路径必须立即出现在下方列表并自动勾选。
- 同一个会话的唯一标识是 `IP/域名 + 用户名 + 工作目录 + AI 类型`。

## CSS 约束

核心布局必须保持：

```css
.session-import-block {
  display: flex;
  flex-direction: column;
  min-height: 0;
}

.session-import-label {
  flex: 0 0 auto;
  padding: 0 8px 8px;
}

.session-import {
  flex: 1 1 auto;
  min-height: 0;
  overflow: hidden;
}

.session-pick-list {
  flex: 1 1 auto;
  min-height: 0;
  overflow: auto;
}
```

移动端低宽度时，自动扫描按钮和手动添加输入区域可以换到下一行，但说明文案仍然在该块底部独立显示。
