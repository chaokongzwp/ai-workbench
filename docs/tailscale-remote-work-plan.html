团队远程办公方案

AI Workbench + Tailscale

每个人在自己的电脑和手机安装 Tailscale。离开办公室后，只需打开 iPhone 上的 AI Workbench，就能安全连接自己的工作电脑，继续使用 Codex、Claude 和已有项目。

不开放公网 SSH 电脑与手机点对点连接 任务可在电脑后台继续

每个人只需要完成四步

首次设置由 IT 或管理员协助完成，之后员工直接打开 App 使用。

01

电脑加入团队网络

安装 Tailscale，用自己的团队身份登录，并由管理员批准设备。

02

准备工作环境

安装 AI Workbench Agent，添加需要使用的项目与 Codex/Claude 会话。

03

手机加入同一网络

安装 Tailscale 和 AI Workbench，登录同一团队并同步工作配置。

04

离开电脑继续工作

手机选择任务、发送指令；电脑在原工作目录执行，结果回到手机。

要稳定使用，必须满足这些条件

真正的远程办公关键不在手机，而在远端电脑是否持续可用。

工作电脑

  • 保持开机、联网，避免进入深度睡眠。
  • Tailscale 和 AI Workbench Agent 随系统启动。
  • Windows 开启 Run Unattended，重启后无需用户先登录。
  • 固定使用 Tailscale 机器名，不依赖变化的局域网 IP。

iPhone / iPad

  • 启用 Tailscale VPN On Demand，网络切换后自动恢复。
  • 与工作电脑加入同一个团队 Tailnet。
  • 首次打开 AI Workbench 时同步会话配置。
  • App 恢复前台后主动查询未完成任务状态。
明确边界： 如果办公室电脑关机、断网或睡眠，手机无法凭空唤醒并连接它。长期使用建议准备一台持续在线的 Mac mini、Windows 主机或服务器；个人笔记本则需要调整电源策略。

App 应该给出可理解的连接状态

用户不需要判断 SSH、端口或网络路由，只需要知道下一步该做什么。

可用 已通过 Tailscale 连接

可以直接发送任务。

电脑离线 目标设备不在 Tailnet

检查电脑是否开机、联网，以及 Tailscale 是否运行。

等待授权 手机或电脑尚未获准加入

联系管理员在 Tailscale 后台批准设备。

Agent 异常 网络可达，但后台服务不可用

App 自动尝试重启 Agent；仍失败时降级为 SSH。

团队安全规则

不能让“安装方便”变成“所有设备互相开放”。

Tailscale 管理

  • 每位员工使用自己的账号，不共享同一个登录身份。
  • 开启设备审批，丢失或离职设备可立即撤销。
  • 使用 Grants 只允许员工访问自己的工作电脑。
  • 只开放 SSH 和 Agent 所需端口，不采用默认全互通。

AI Workbench 管理

  • 服务器密码保存在设备安全存储，不同步聊天记录。
  • 重要操作仍由远端 Codex/Claude 的权限策略控制。
  • 同一会话同时只运行一条任务，避免多设备互相干扰。
  • 保留连接、任务与错误日志，方便员工导出诊断。

建议分三步落地

先验证真实办公场景，再逐步扩大，不需要一次性改造所有电脑。

第一阶段 · 试点

3–5 人使用一周

覆盖 Mac、Windows、iPhone 和不同网络，记录离线、睡眠和任务恢复问题。

第二阶段 · 标准化

固化安装与权限

统一机器命名、设备审批、Grants、Agent 自启动和诊断日志。

第三阶段 · 推广

员工自助接入

App 引导登录、检测 Tailscale、同步配置，并明确展示电脑离线原因。
