AI Workbench · PRD 与架构方案总览

AI Workbench 是连接用户自己机器上 Codex 与 Claude 的多端工作台。App 负责会话、任务与结果；远端 Agent 负责持续执行和保存任务状态。用户无需看 SSH、tmux 或终端噪声，但随时能查看可读的任务进度与诊断。

已实现：Agent 后台任务 已实现：HTTP 任务接口 已实现：本地消息与配置同步 持续优化：多端体验与语音

一页结论

产品定位

不是重新做 Codex 或 Claude，而是做多端工作台：复用用户机器上的 CLI、工作目录和远端 Agent，把终端操作收进可读界面。

核心体验

会话以服务器、登录账号、工作目录和 AI 类型确定。用户发出任务后立即看到自己的消息；Agent 接收、AI 执行和最终结果都更新到同一条回复。

稳定恢复

App 进入后台或被杀掉不会中止 Agent 任务。再次打开或回到前台时，只同步当前会话最后一条未结束任务。

关键原则

连接状态和任务状态严格分开：顶部只表达通道是否可用；聊天消息只表达这一次任务的阶段与结果。

需求 PRD

1. 背景问题

  • 直接使用 SSH、tmux 和 CLI 对移动端不友好，且 App 退出后难以知道远端任务是否还在执行。
  • 同一台机器可以有多个项目与多个 AI 会话；多设备进入同一会话时，必须避免重复下发任务。
  • 用户只需要结果和必要进度，不能被 CLI 启动信息、模型选择提示或原始终端输出干扰。

3. 不做什么

  • 不重新训练或替代 Codex/Claude，本产品只做交互入口、调度和结果整理。
  • 不默认展示 SSH、tmux、命令窗口和完整终端日志；它们只在 SSH 面板或诊断详情中按需打开。
  • 不在高风险操作上自动执行，例如删除文件、发布、付款、改生产配置等。
  • 不把完整聊天记录上传到云端；云端只保存用户加密后的配置包。

任务与状态

当前任务模型只有一个核心原则：连接是机器状态，任务是消息状态。顶部显示通道是否可用；消息区显示这条请求是否已经被 Agent 接收、是否由 AI 执行、以及是否有最终结果。

1. 本地落盘立即保存用户消息与 AI 占位消息，用户不用等网络才看到自己已发送。
2. Agent 接收优先通过 HTTP 创建任务，拿到唯一 remoteTaskId；同会话已有任务则拒绝重复提交。
3. AI 执行Agent 在远端启动 Codex 或 Claude，可持续写入中间输出与状态。
4. 查询或推送App 优先通过 Agent HTTP 查询指定任务；WebSocket 可推送变化，SSH 仅作回退。
5. 终态成功、失败、取消都是结束；更新同一条回复，输入框立即解锁。

用户可见状态

状态判断依据系统动作
准备发送 / 正在发送本地已保存，正在建立通道或创建远端任务。锁定输入。
Agent 已接收远端返回 queued 或 preparing。锁定输入，等待 AI 启动。
AI 执行中远端返回 running 或已有中间输出。锁定输入，可停止或刷新。
正在同步结果App 回前台、重连或手动刷新指定任务。锁定输入，保留原任务 ID。
AI 回复 / 失败 / 已取消done、error 或 cancelled。解锁输入。
前后台恢复：App 回到前台时，只查询当前会话最后一条未结束 Agent 任务。先立即查询；只有连接失败才在 1.5 秒后重试一次。已完成、失败或取消的任务不会重复同步。

语音与主 AI

语音是当前 App 的输入与播报能力，不改变任务协议：唤醒后 ASR 实时写入输入框，用户或自动发送动作仍走同一条 Agent 任务链路。TTS 可播报任务完成或最后结果，并允许打断。

唤醒与转写

默认关闭；启用后由唤醒词进入 ASR，唤醒前声音不进入任务文本。

任务播报

可选择只播报“任务完成”，或直接播放最后一条结果；播放中可打断。

人工主控

当前由用户选择会话与 AI，风险操作仍应由用户确认。

未来主 AI

只做自然语言理解与结构化意图，不直接 SSH、不伪造任务完成。

项目与角色

一个工作目录可以有多个 AI 协作者；角色是任务视角，不是固定传统岗位。

CLI 能力目录

未来主 AI 通过固定能力清单调用 App，不自行猜测底层命令。

验收与排查

  • 用户发送后，自己的消息与 AI 占位消息立即出现在当前会话；网络慢不应让输入停留在输入框。
  • Agent 接收任务后，App 必须保存 remoteTaskId；刷新、停止和恢复都复用这个 ID，不创建新任务。
  • 顶部“已连接”与消息“AI 执行中”可以同时存在，但聊天区不能再显示过期的“连接中”。
  • App 回前台时，只同步当前会话最后一条未结束任务；终态任务不重复查询。
  • 同一会话在任意设备执行时，其他设备的新请求必须被拒绝或等待用户先停止前任务。
  • 完整聊天历史只从本地读取；云端只同步加密会话配置，远端只用于恢复最后任务状态。
  • Mac、iPhone、iPad、Android 各自适配布局，业务状态机共用，不能用一个平台的 CSS 修另一个平台。

排查顺序

问题为什么重要建议默认值
