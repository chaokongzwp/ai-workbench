# 添加工作会话字体规范

这个规范只约束“添加工作会话 / 会话连接配置”页面，目标是接近 iOS / iPadOS 设置页密度，不做展示稿式大字。

| 场景 | 字号 | 字重 | 行高 | 说明 |
|---|---:|---:|---:|---|
| 页面标题 | 24px | 760 | 1.12 | iPhone 可降到 22px，禁止超过 24px |
| 页面副标题 | 12px | 400 | 1.32 | 只做辅助说明 |
| 区块标题 | 17px | 720 | 1.2 | 例如“工作目录” |
| 区块说明 | 12px | 400 | 1.38 | 放在区块标题下方、卡片外面 |
| 表单字段名 | 13px | 560 | 1.25 | 例如“服务器地址”“用户名” |
| 表单输入值 | 14px | 400 | 1.25 | IP、端口、用户名、密码等 |
| 方法标题 | 14px | 700 | 1.25 | 自动扫描、手动添加 |
| 方法说明 | 12px | 400 | 1.38 | 独立一行，不和输入框挤在一起 |
| 目录名称 | 14px | 700 | 1.25 | 工作目录列表主文本 |
| 目录路径 | 12px | 400 | 1.3 | 可使用等宽字体 |
| 目录元信息 | 12px | 400 | 1.3 | 例如“最近使用”“历史会话” |
| 普通按钮 | 13px | 700 | 1 | 高度 34-36px |
| 底部主按钮 | 14px | 720 | 1 | 高度 44-46px |

硬性规则：

- 不使用 `vw`、`vh` 或容器宽度控制字号。
- 不使用负字距。
- 添加会话页不出现 28px 以上标题。
- 操作说明不要做成大段正文，控制在一到两行。
- 手动添加使用普通输入框和文字按钮，不能改成透明设置行，也不能只放一个小图标按钮。
